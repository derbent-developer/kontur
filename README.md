# Kontur — сайт центра аппаратной коррекции фигуры (Дербент)

Статический одностраничный сайт. Никаких сборщиков и зависимостей — просто выложить папку на хостинг.

## Структура

```
kontur/
├── index.html            вся разметка страницы
├── assets/
│   ├── css/styles.css    стили
│   ├── js/main.js        меню, галерея-лайтбокс, отзывы, форма
│   └── img/              логотип и фотографии
└── README.md
```

## Как посмотреть локально

Двойной клик по `index.html` тоже сработает, но логотип корректнее
собирается при запуске через локальный сервер:

```bash
python3 -m http.server 8000 --directory ~/Desktop/kontur
```

Затем открыть http://localhost:8000

## Как выложить

Подойдёт любой статический хостинг: Timeweb, Beget, reg.ru, GitHub Pages, Netlify, Vercel.
Залить содержимое папки `kontur/` в корень сайта — и всё.

## Анимации

Всё на CSS-переходах и одном `requestAnimationFrame`-цикле — без библиотек.

- появление блоков при прокрутке (`.reveal`, направление задаётся `data-anim`,
  задержка каскада — инлайновой переменной `--d`);
- «шторка» для фотографий (`.unveil`) с лёгким наездом камеры;
- мягкий параллакс (`.parallax` + `data-speed`);
- докрутка чисел в блоках статистики (`data-count`);
- полоса прогресса чтения вверху;
- шапка прячется при движении вниз и возвращается при движении вверх.

Всё отключается системной настройкой «уменьшить движение»
(`prefers-reduced-motion`) — блоки просто показываются сразу.

## Мобильная версия

Сайт делался с расчётом в первую очередь на телефон:

- услуги, результаты и фотогалерея превращаются в ленты со свайпом
  и «примагничиванием» карточек — страница короче почти на треть;
- отзывов сразу видно три, остальные раскрываются кнопкой;
- внизу закреплена панель «Позвонить / WhatsApp» (появляется после первого экрана);
- в шапке остаются только логотип и меню, кнопка записи уходит в меню.

## Форма записи

Бэкенда нет: форма собирает текст и открывает WhatsApp с готовым сообщением
на номер +7 918 736-03-36. Если понадобится отправка на почту или в CRM —
меняется обработчик `bookingForm` в `assets/js/main.js`.

## Логотип

Исходник — JPEG с белым фоном. `main.js` при загрузке пересобирает его в PNG
с прозрачностью и обрезает поля, поэтому логотип корректно смотрится и на светлом
фоне, и на тёмном футере. Если появится векторный логотип (SVG/PNG с альфа-каналом) —
положить его в `assets/img/`, поменять три `<img ... data-logo>` в `index.html`
и атрибут `data-logo` можно убрать.
